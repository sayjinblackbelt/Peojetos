# Interface Web do Dashboard

Esta pasta contém uma interface web estática para apresentar o dashboard demonstrativo.

## Tecnologias

- HTML;
- CSS;
- JavaScript;
- dados CSV;
- gráficos gerados por Python.

## Execução local

Para evitar restrições do navegador ao carregar arquivos CSV localmente, recomenda-se iniciar um servidor simples:

```bash
python -m http.server 8000
```

Depois, acessar:

```
http://localhost:8000/web/
```

## Publicação

A interface pode ser publicada usando GitHub Pages.

Os dados são fictícios e utilizados exclusivamente para demonstração.
