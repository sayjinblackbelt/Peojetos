# Dados Demonstrativos

Os dados utilizados nesta pasta e nas automações são fictícios ou simulados.

Eles não representam informações, indicadores, documentos ou dados operacionais de qualquer empresa em que o autor tenha trabalhado.

A finalidade é exclusivamente demonstrar:

- organização de dados;
- automação;
- indicadores;
- dashboards;
- controle de requisitos;
- práticas de PMO.
