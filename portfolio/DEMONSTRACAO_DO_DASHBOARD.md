# Demonstração — Dashboard de PMO

## Objetivo

Demonstrar uma evolução prática do case por meio de automação e indicadores.

## Dados

O dashboard utiliza dados totalmente fictícios armazenados em:

- `automation/sample_data/project_documents.csv`
- `automation/sample_data/project_requirements.csv`

## Execução

```bash
python automation/advanced_dashboard.py
```

## Informações geradas

- total de documentos;
- documentos por status;
- progresso médio;
- avanço por disciplina;
- total de requisitos;
- percentual concluído;
- pendências prioritárias;
- índice demonstrativo geral.

## Competência demonstrada

Este exemplo conecta experiência de PMO com competências atuais de programação e automação:

PMO → Dados estruturados → Python → Indicadores → Tomada de decisão.
