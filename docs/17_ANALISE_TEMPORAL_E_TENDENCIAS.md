# Análise Temporal e Tendências

## Objetivo

Demonstrar acompanhamento de evolução de um projeto ao longo do tempo.

## Indicadores

O módulo acompanha:

- progresso semanal;
- índice de risco;
- documentos concluídos;
- documentos pendentes.

## Previsão

A versão demonstrativa calcula uma projeção linear simples:

1. mede a evolução média do progresso;
2. calcula o ritmo semanal;
3. estima quantas semanas seriam necessárias para atingir 100%.

A previsão é apenas um indicador demonstrativo e não substitui planejamento formal.
