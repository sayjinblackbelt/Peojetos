# Checklist de Levantamento de Campo

## Área

- [ ] Dimensões registradas
- [ ] Acessos identificados
- [ ] Circulação observada
- [ ] Instalações adjacentes registradas
- [ ] Interferências identificadas

## Equipamentos

- [ ] Equipamentos existentes identificados
- [ ] Plaquetas e dados disponíveis registrados
- [ ] Pontos de abastecimento identificados
- [ ] Linhas e conexões observadas

## Civil e drenagem

- [ ] Piso avaliado
- [ ] Drenagem identificada
- [ ] Canaletas e contenções verificadas
- [ ] Áreas sujeitas a acúmulo identificadas

## Elétrica

- [ ] Fonte de alimentação identificada
- [ ] Quadros próximos registrados
- [ ] Iluminação observada
- [ ] Aterramento visível registrado

## Segurança

- [ ] Fontes potenciais de ignição identificadas
- [ ] Recursos de emergência observados
- [ ] Sinalização registrada
- [ ] Acessos de emergência avaliados

## Evidências

- [ ] Fotografias organizadas
- [ ] Croquis produzidos
- [ ] Pendências registradas
- [ ] Dados críticos confirmados com responsável local
