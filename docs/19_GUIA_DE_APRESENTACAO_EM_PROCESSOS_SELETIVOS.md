# Guia de Apresentação em Processos Seletivos

## Pitch curto

> Desenvolvi um case que conecta minha experiência com PMO e documentação técnica às minhas competências atuais em Python, automação e desenvolvimento web. O sistema utiliza dados fictícios para demonstrar validação documental, análise de risco, tendências e publicação automatizada.

## Demonstração sugerida

1. abrir o README;
2. explicar a arquitetura;
3. mostrar o dashboard;
4. destacar análise documental;
5. mostrar risco e prioridades;
6. explicar o GitHub Actions;
7. discutir possíveis evoluções.

## Como apresentar corretamente

Evite apresentar o projeto como sistema utilizado por empresa real.

Prefira:

- case técnico;
- demonstração;
- arquitetura reproduzível;
- dados fictícios;
- competências transferíveis.

## Perguntas técnicas possíveis

### Por que Python?

Automação, manipulação de dados e facilidade de integração.

### Por que regras antes de IA?

Transparência e previsibilidade antes de introduzir modelos probabilísticos.

### Como evoluir?

API, banco de dados, autenticação, integração com planilhas e análise assistida por IA.
