# Automação de Processos de PMO

## 1. Objetivo

Demonstrar possibilidades de aplicação de automação à gestão documental e ao acompanhamento de projetos.

## 2. Processos candidatos

- cadastro de documentos;
- controle de revisões;
- identificação de pendências;
- atualização de status;
- geração de listas mestras;
- consolidação de requisitos;
- geração de relatórios;
- acompanhamento de indicadores.

## 3. Fluxo proposto

Documentos → Registro automático → Validação → Base estruturada → Indicadores → Alertas.

## 4. Tecnologias possíveis

- Python;
- Google Sheets;
- Google Apps Script;
- APIs REST;
- GitHub;
- GitHub Actions;
- bancos de dados;
- ferramentas de automação;
- inteligência artificial.

## 5. Aplicação de IA

A IA pode apoiar a classificação documental, identificação de informações ausentes, comparação de versões, resumo de pendências e preparação inicial de relatórios.

Toda decisão técnica ou aprovação formal deverá permanecer sob responsabilidade das pessoas e profissionais designados.
